# 🌿 로봇팔 기반 사과나무 병충해 탐지 시스템

> 한국기계연구원(KIMM) 현장실습 · 2024.03 – 2024.08

로봇팔 기반 실시간 스트리밍 환경에서 사과나무의 병충해를 조기 탐지하기 위해  
Object Detection 및 Instance Segmentation 모델을 개발하고 최적화한 프로젝트입니다.

📄 [발표 자료 PDF](./20240730_seminar_포트폴리오.pdf)

---

## Tech Stack

| 분류 | 기술 |
|---|---|
| AI / Vision | YOLOv8 (x6, seg), SAM (Segment Anything Model), PyTorch |
| 데이터 전처리 | OpenCV, NIR 이미지 분석, LabelMe |
| 개발 환경 | Python, Jupyter Notebook, Anaconda |

---

## 주요 기여

### 1. 고해상도 객체 탐지 모델 최적화
초기 모델의 낮은 탐지율을 해결하기 위해 YOLOv8x6 모델을 도입하고,  
입력 이미지 사이즈를 1280으로 확장하여 실시간 스트리밍 환경에서의 병충해 탐지 정확도를 극대화함.

### 2. SAM 기반 오토 라벨링 (Reverse Labeling)
부족한 Segmentation 데이터셋 문제를 해결하기 위해 SAM을 활용한 Reverse Labeling 기법을 도입.  
수동 라벨링 10장 → 80장으로 데이터 8배 확보, 라벨 경계 정밀도 향상.

### 3. NIR 기반 도메인 특화 전처리
RGB 채널 대신 NIR(근적외선) 채널 데이터로 교체하여 조명 영향을 최소화하고,  
Sharpness 필터를 적용하여 나뭇잎 경계 분할 성능을 개선함.

### 4. 로봇팔 환경 실시간 테스트 완수
실제 로봇팔 스트리밍 환경(Video Size 640)에서 End-to-End 실시간 추론 테스트 성공.  
산업 현장 적용 가능성 입증.

## 트러블슈팅

### 문제: Instance Segmentation 초기 모델 동작 불가

**현상**  
수동 라벨링으로 확보한 초기 데이터 10장, 20 epochs 학습 결과  
Segmentation이 전혀 동작하지 않는 수준의 성능.

**가설**  
데이터 부족 및 라벨 품질 저하(경계점 부정확)가 원인으로 판단.

**해결 과정**

| 단계 | 내용 | 결과 |
|---|---|---|
| 해결 1 · 데이터 | SAM Reverse Labeling 도입 | 10장 → 80장 (8배), 경계 정밀도 향상 |
| 해결 2 · 채널 | RGB → NIR 채널 분리 + Sharpness 필터 적용 | 잎사귀·배경 구분 명확화, 오검출 감소 |

**결과**  
실시간 스트리밍 환경(Video Size 640)에서 병증 탐지 완수.
